# BoneController リファクタリング

## 概要
MMDモデルのボーンをマウス入力に基づいて制御するBoneControllerをリファクタリングしました。
機能は元のままに、見やすさと変更しやすさを大幅に改善しています。

## 変更内容

### 🔧 主な改善点
1. **マジックナンバーの排除**: ハードコーディングされた数値を設定として分離
2. **コードの整理**: 責任を明確に分離し、メソッドを細分化
3. **設定の可視化**: インスペクターで設定を確認・編集可能
4. **エラーハンドリング**: ボーンが見つからない場合の適切な警告
5. **デバッグ機能**: リアルタイムでマウス入力を確認可能

### 📁 ファイル構成

#### 基本版
- `BoneController.cs` - リファクタリング済みの基本版
  - 元の機能を保持
  - コードの見やすさを大幅改善
  - 設定値を構造体で管理

#### 高機能版
- `BoneControllerAdvanced.cs` - 設定可能な高機能版
  - インスペクターで全設定を編集可能
  - ボーンごとの有効/無効切り替え
  - デバッグ用コンテキストメニュー

#### 拡張用コンポーネント（将来の機能拡張用）
- `BoneSettings.cs` - ボーン設定データクラス
- `MouseInputHandler.cs` - マウス入力処理
- `BoneAnimationConfig.cs` - ScriptableObject設定
- `ReadOnlyPropertyDrawer.cs` - エディター用カスタムドロワー

## 使用方法

### 基本版を使用する場合
1. 既存の`BoneController`を新しい`BoneController.cs`に置き換え
2. インスペクターで`Turn Proportional Bias`を調整（デフォルト: 4.5）
3. デバッグ情報で現在のマウス入力を確認可能

### 高機能版を使用する場合
1. `BoneControllerAdvanced`コンポーネントを追加
2. インスペクターで以下の設定が可能：
   - **基本設定**: 感度とマウス追従の有効/無効
   - **初期ポーズ設定**: ボーン名と初期回転角度
   - **マウス追従設定**: ボーンごとの動作倍率と制限

### 設定項目の説明

#### マウス追従設定
- **Motion Multiplier**: 
  - X: 上下の動きに対する反応倍率
  - Y: 左右の動きに対する反応倍率  
  - Z: 左右の捻りに対する反応倍率
- **Motion Limit**: 各軸の最大回転角度（度）

#### デバッグ機能
- **Reset to Default Settings**: 設定をデフォルトに戻す
- **Debug: Print Available Bone Names**: 利用可能なボーン名をコンソールに出力

## マイグレーション

既存のプロジェクトから移行する場合：

1. **バックアップを作成**
2. 既存の`BoneController.cs`を置き換え
3. インスペクターで設定を確認
4. 必要に応じて感度を調整

動作は元のコードと完全に同じですが、設定が可視化され変更が簡単になります。

## カスタマイズ例

新しいボーンを追加する場合（高機能版）：

```csharp
// Mouse Tracking Settingsに新しい要素を追加
boneName: "新しいボーン名"
motionMultiplier: (1.0, 1.0, 0.5)  // 適切な倍率を設定
motionLimit: (15, 10, 5)           // 適切な制限を設定
enabled: true
```
